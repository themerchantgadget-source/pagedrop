How it works

  1. Enter a GitHub token.
  2. Select one HTML file.
  3. PageDrop creates a public repo and uploads it as index.html.
  4. GitHub builds Pages and the direct URL appears here.
⌁

Token stays local

There is no server behind this tool. The token exists only in this browser tab while you publish and is not placed in the repository or URL.

For maximum safety, create a dedicated fine-grained token and revoke it after publishing if you do not plan to reuse this tool.
